# ACLED public aggregates (HDX)
- https://data.humdata.org/dataset/south-sudan-acled-conflict-data (ssd_*.xlsx: admin-2 x month, political violence / civilian targeting / demonstrations)
- https://data.humdata.org/dataset/sudan-acled-conflict-data (sdn_*.xlsx: used only for Admin1 'Abyei' -> SS0001)

ACLED terms of use apply. Event-level data / political violence targeting women require an ACLED account (acleddata.com).
